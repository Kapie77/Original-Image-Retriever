INFORMATION & SECURITY

What Is the WebP Format?

Learn how this image format works and what precautions to take when downloading images from the internet.

What Is WebP?

WebP is an image format developed by Google that generally produces smaller file sizes while maintaining good visual quality. It supports both lossy and lossless compression, as well as transparency and animation.

Some websites use WebP to reduce data usage and speed up page loading. As a result, an image that was originally available as a PNG or JPG may be delivered to your browser in WebP format instead.

Does WebP Pose Security Risks?

The WebP format is not inherently dangerous. However, as with any image format, malicious files may exploit vulnerabilities in outdated programs or libraries used to process them.

Keep your browser and software up to date, and avoid opening files from unknown sources with outdated applications. Changing a file's extension does not eliminate potential threats.

What About Privacy?

The WebP format itself does not allow an image to track you. However, when you access an image hosted on an external server, that server may log connection information such as your IP address, access time, and technical details about your request.

Images may also contain metadata, depending on how they were created and processed. This information can reveal details about the file or its origin.

How Does OIR Handle WebP Images?

The Original Image Retriever attempts to retrieve an alternative version of an image whenever possible. If the server continues to deliver WebP and no other format can be obtained, the program disables the download instead of automatically converting the file.

This limitation prevents a converted image from being presented as the original file. It does not mean that WebP is unsafe, nor does it guarantee that images in other formats are safe.

Important: OIR cannot guarantee that external files are safe or that a retrieved image exactly matches the file originally uploaded by its creator. Only download files from sources you trust.
